### 5.3 首轮 2 项失败的定位说明（非应用缺陷）

首轮执行时 `C35/C36`（榜单详情）返回 404/40401，经开启 MyBatis SQL 日志定位：请求路径被解析为 `/api/interaction/ranking/=ALL`，实际传入 `rankingCode="=ALL"`。

- 根因：测试脚本使用 PowerShell 双引号字符串拼接 `".../$rankCode?periodNo=ALL"`，其中 `$rankCode?periodNo` 被 PowerShell 解析为单个变量名，导致路径变量丢失。属**测试脚本缺陷**。
- 处理：改为显式字符串拼接后重新完整执行，135 项全部通过；随后用 `curl` 直接请求同一接口返回 200，确认服务端逻辑正确。
- 责任模块：测试脚本（非 A/B/C/D 业务代码）。

## 七、尚未解决的问题与风险

1. **A 模块缺少充值接口**：联调需通过测试库直接调整 `user_account.balance`。不影响交易正确性验证，但属功能缺口（建议补管理端/测试充值能力）。
2. **缺少作者申请/角色变更接口**：作者身份需在测试库将 `role` 改为 `AUTHOR` 后重新登录获取新令牌；建议补充角色申请或后台角色管理能力（涉及 A/D 职责划分，需产品确认）。
3. **退款后无法再次订阅**：当前对 `REFUNDED` 订阅仍返回 `ALREADY_SUBSCRIBED`，用户退款后无法重新购买同一章节。属业务规则问题，**未擅自修改**，需产品确认。
4. **正式环境 JWT 密钥**：`app.jwt.secret` 存在开发默认值，生产必须通过 `JWT_SECRET` 注入强随机密钥（安全加固项）。
5. **测试实例非系统服务**：实例运行于本地临时目录，主机重启后需按 2.1 的启动命令重新拉起；建议后续改为 Windows 服务或容器化。
6. **并发测试规模有限**：本次为单机 6 并发订阅 / 4 并发打赏，未做高压力、长事务、故障注入测试。
7. **前端构建警告**：主 chunk 约 880 kB，仅有体积提示，不阻塞交付。
8. **历史 47 项 SQL 集成脚本未在本轮复跑**：该脚本为数据库对象级证据，且设计为特定测试数据断言；本轮已有真实接口级联调，避免与联调数据混跑造成误判。
