## 1. 测试范围与执行原则

本次覆盖用户与账户、作品发布、章节订阅、作品打赏、评论互动、小说评分、四类内容审核和榜单功能。每项测试均通过 `sp_it_assert` 记录结果；断言失败时写入 `FAIL` 并抛出异常，不使用 `--force` 忽略错误。

事务边界按模块契约分别处理：

- A 模块订阅、打赏过程自行管理事务，调用前不开启外层事务。
- B 模块建书、草稿、发布、下架过程自行管理事务，调用前不开启外层事务。
- 评论、评分统计刷新和榜单公共过程由调用方显式管理事务。
- D 模块状态更新与审核日志在同一调用方事务中执行。

测试用户采用 `910000000000000001` 至 `910000000000000006` 的专用 ID 段，请求号采用 `IT-` 前缀，榜单编码采用 `IT_` 前缀。测试前检查这些标识不存在，测试后仅按本次 ID、作品 ID 和编码清理数据。

本次未连接或修改现有 3306 实例，未操作正式数据库 `novel_platform`，未修改 A/B/C/D 模块 SQL、原始全局 SQL、数据库设计文件或冻结表结构。
