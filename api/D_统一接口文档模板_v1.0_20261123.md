## 1. 基本信息

| 项目 | 内容 |
|---|---|
| 接口名称 | 例如：查询后台统计摘要 |
| 请求地址 | `/api/{module}/{resource}` |
| 请求方式 | GET / POST / PUT / DELETE |
| 接口说明 | 一句话说明用途及调用时机 |
| 鉴权要求 | 公开 / 登录用户 / 管理员；凭证传递方式待鉴权模块确定后填写 |
| 内容类型 | `application/json`；GET 无请求体时写“无” |
| 数据来源 | 真实数据库 / 公共过程 / MOCK（联调期间必须明确） |
| 幂等要求 | 是否可重复调用；写接口说明防重复策略 |
| 事务要求 | 无 / 调用方事务边界、公共过程及需同时成功或回滚的操作 |

## 2. 请求参数

### 2.1 路径参数

无路径参数时写“无”。

| 参数 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| `id` | String | 是 | `"1001"` | 数据库 BIGINT ID 在 JSON 中使用字符串 |

### 2.2 Query 参数

无 Query 参数时写“无”。GET 查询不得把 JSON 请求体作为常规传参方式。

| 参数 | 类型 | 必填 | 默认值 | 示例 | 校验与说明 |
|---|---|---|---|---|---|
| `page` | Integer | 否 | 1 | 1 | 从 1 开始 |
| `pageSize` | Integer | 否 | 10 | 10 | 1～100 |
| `keyword` | String | 否 | 无 | `"示例"` | 最大长度及匹配规则 |

### 2.3 请求体

无请求体时写“无”。

| 字段 | 类型 | 必填 | 示例 | 校验与说明 |
|---|---|---|---|---|
| `exampleName` | String | 是 | `"示例"` | 长度、格式、枚举或业务约束 |

请求示例：

```http
POST /api/{module}/{resource} HTTP/1.1
Content-Type: application/json
```

```json
{
  "exampleName": "示例"
}
```

## 3. 成功响应

### 3.1 响应字段

统一外层结构为 `ApiResponse<T>`，成功时 `code=0`、`message="success"`。

| 字段 | 类型 | 必返 | 说明 |
|---|---|---|---|
| `code` | Integer | 是 | 固定为 0 |
| `message` | String | 是 | 固定为 `success` |
| `data` | Object / Array / null | 是 | 实际业务数据，无数据时为 null |

继续列出 `data` 内部字段；嵌套对象和数组需写清元素结构。

| 字段 | 类型 | 必返 | 说明 |
|---|---|---|---|
| `data.exampleId` | String | 是 | BIGINT ID 使用字符串 |
| `data.exampleName` | String | 是 | 字段业务含义 |
| `data.createdAt` | String | 否 | ISO 8601 日期时间，注明时区 |

### 3.2 响应示例

```http
HTTP/1.1 200 OK
Content-Type: application/json
```

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "exampleId": "1001",
    "exampleName": "示例",
    "createdAt": "2026-11-23T10:00:00+08:00"
  }
}
```

列表接口的 `data` 统一建议采用：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [],
    "total": 0,
    "page": 1,
    "pageSize": 10
  }
}
```

## 4. 错误说明

公共错误至少检查下表；模块业务错误需补充触发条件，不得只写“操作失败”。

| HTTP 状态 | 业务码 | 触发条件 | message 示例 | 调用方处理 |
|---|---:|---|---|---|
| 400 | 40000 | 缺少必填参数、格式或校验失败 | `exampleName: 不能为空` | 修正输入后重试 |
| 401 | 待定义 | 未登录或凭证失效 | `未登录或登录已失效` | 跳转登录；实现鉴权后登记最终业务码 |
| 403 | 待定义 | 已登录但无操作权限 | `无权执行该操作` | 停止重试并提示权限不足 |
| 404 | 40400 | 请求地址不存在 | `接口不存在` | 检查地址；资源不存在时由模块另定业务码 |
| 409 | 待定义 | 状态冲突或重复提交 | `当前状态不允许该操作` | 刷新状态，不盲目重试 |
| 500 | 50000 | 未处理服务器异常 | `服务器内部错误` | 记录问题并联系后端，不展示堆栈 |

失败响应示例：

```json
{
  "code": 40000,
  "message": "exampleName: 不能为空",
  "data": null
}
```
